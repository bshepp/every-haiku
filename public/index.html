How the library is built

Nothing here is stored. A haiku is computed from its address and the address is computed from the haiku, so the whole library fits in one small file and a page can never be lost.

The library has a vocabulary of a few hundred words, each sorted by its syllable count, and a set of line shapes: twenty for five-syllable lines and twenty-two for seven. A hall is one choice of shape for each of the three lines, so there are halls. Inside a hall the words turn over like the digits of an odometer, last slot fastest, which is why walking to the next address changes one word.

Add up every hall and you get the total at the top of the page. It is finite. If you search for a word the vocabulary does not contain, the library will tell you so honestly: that poem is in some other library.

“Wander” picks a hall first and then a shelf inside it, so every grammatical shape turns up equally often. “Strict random” draws uniformly from all addresses, which almost always lands in the biggest halls. Both are real addresses.

With apologies and thanks to Jorge Luis Borges, and to Jonathan Basile’s Library of Babel.
